CLAUDE THREE-PART RUN / PRIMARY-SOURCE RECHECK

A Hermes bridge, more visualizers, and firmer cost evidence.

Miniverse plus hermes-miniverse provide a documented path for real agents in a shared pixel world. The main Hermes Pixel Office plugin, paulrobello's distinct Claude Office, and pixtuoid widen the visualizer shortlist.

Lyfe Agents and Affordable Generative Agents add historical cost/token evidence. We also corrected the original Smallville cost claim: its paper does say "thousands of dollars in token credits".
